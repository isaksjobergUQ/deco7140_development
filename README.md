# International Student Platform - DECO7140

This project is a comprehensive web platform designed to support international students in their transition to Australian university life. The development follows a structured four-phase approach: Work Phase 1 establishes the design foundations including color schemes, typography, spacing, and reusable components. Work Phase 2 focuses on research and analysis, covering accessibility assessments, client needs analysis, ethics considerations, and user story development. Work Phase 3 presents the complete design proposal with behavioural design patterns, ethical responses, reflective design documentation, site maps, style guides, and visceral design explorations. Work Phase 4 contains the final functional implementation featuring a responsive website with pages for tips, events, community forums, language support, contact forms, and user profiles. The platform includes multi-language support (English and Chinese), local storage for bookmarks and user data, and a mobile-first responsive design approach. All CSS follows a modular structure with base styles, layout utilities, component styles, and page-specific stylesheets. JavaScript modules handle data fetching, internationalization, storage management, and interactive components like accordions and image viewers. The project adheres to WCAG 2.2 accessibility standards and emphasizes inclusive design principles throughout.
